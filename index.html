building the glass box

Mahmood U, Fu Z, Ghosh S, Calhoun V, Plis S. Through the looking glass: deep interpretable dynamic directed connectivity in resting fMRI. NeuroImage, 2022.
Mahmood U, Fu Z, Calhoun V, Plis S. Glacier: glass-box transformer for interpretable dynamic neuroimaging. IEEE ICASSP, 2023.
Build it step by step. Start: ICA time courses, one per region. 1. The same encoder reads each region's time course on its own, with shared weights. biLSTM in DICE, transformer in Glacier. A black box, but region i goes in and embedding i comes out, so we always know which node is which in the attention matrix. Follow the colors. 2. At every time point, self-attention across regions gives a directed weight matrix. No sliding window, so no window-size choice. 3. Temporal attention scores each moment and sums the graphs into one. 4. Only that graph reaches the classifier. The features do not. So whatever the model uses to predict must be in the graph.
Usman Mahmood

how the graph is computed

$\mathbf{h}^i_t = \mathrm{enc}\big(x^i_{1:T}\big)_t \qquad \mathbf{H}_t = \big[\mathbf{h}^1_t;\,\dots;\,\mathbf{h}^n_t\big]$

each region encoded on its own, so row $i$ is region $i$: biLSTM (DICE) or transformer (Glacier)

$\mathbf{W}_t = \mathrm{softmax}\big(\mathbf{H}_t\,\mathbf{W}^{(q)}\,\mathbf{W}^{(k)\top}\mathbf{H}_t^{\top}\big)$

all regions at once: the attention alignment matrix is the directed graph at time $t$

$\alpha_t = \mathrm{MLP}\big(\mathrm{flat}(\mathbf{W}_t \odot \overline{\mathbf{W}})\big) \qquad \mathbf{W}^f = \sum_{t=1}^{T} \alpha_t\,\mathbf{W}_t$

temporal attention: which moments matter

$\hat{y} = \mathrm{MLP}\big(\mathbf{W}^f\big)$

only the graph reaches the classifier

Mahmood U, Fu Z, Ghosh S, Calhoun V, Plis S. Through the looking glass: deep interpretable dynamic directed connectivity in resting fMRI. NeuroImage, 2022.
Mahmood U, Fu Z, Calhoun V, Plis S. Glacier: glass-box transformer for interpretable dynamic neuroimaging. IEEE ICASSP, 2023.
H_t stacks the region embeddings as rows. Row i of W_t holds how much region i draws on every other region at time t. This is eq. 2 of the DICE paper written with all regions in one matrix; the softmax runs over each row. Query and key maps differ, so W_t is not symmetric: that is where direction comes from. W-bar is the mean of W_t over time, the global view. Each moment is scored by how it relates to that global view. DICE and Glacier differ only in the encoder.

what do the edges mean?

causally informed, not yet causal

  • no hidden confounders
  • BOLD keeps the neural time order
  • forecasting finds directed influence
All cross-region mixing must pass through the transition matrix, and the matrix is trained to forecast the future. That makes edges directed and grounded in time order. It does not make them verified causes. Three assumptions stand between the two: causal sufficiency, time alignment of BOLD with neural dynamics (hemodynamic response varies by region), and that forecasting captures influence, not just association. Validation on systems with known causal structure is future work.

What's next?

counterfactuals through the bottleneck

Monday's digital twin, with wiring you can read and cut

This is the counterfactual model from Monday's first talk. The difference: every prediction passes through a named graph, so cutting or turning down an edge changes the forward simulation itself. Start from the same state, run both, compare. These are model-based counterfactuals. They are valid only as far as the learned graph captures the process that made the data. DECIFRA has the algebra in place. Nobody has run the edge edits yet. Open direction.

Xiao Y, Silva RF, Baker BT, Calhoun VD, Plis SM. Batch perfect: BSS via structured local covariance. IEEE ICIP, 2026.
1. Evidence so far: the 5% result and the identity ablation. No proof yet. 2. How to construct a layer that learns a causal graph in the interventional sense? 3. How to use a truly black-box encoder and still get the model to learn interpretable nodes? 4. How to make sure the nodes are independent mechanisms? Nodes: an edge is only as readable as its nodes. Today ICA gives the nodes meaning before the model sees them. JDX is a differentiable way to impose independence on any layer, so nodes can be learned and stay readable.
